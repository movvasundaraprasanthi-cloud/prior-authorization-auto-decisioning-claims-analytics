# Dashboard Specification

## Dashboard Name

Cohere-Style Prior Authorization Analytics Monitor

## Audience

Analytics, Client Delivery, Product, IPA/rule-refinement team, payer clients, operational leadership.

## Page 1: Executive Performance

Six-second view:
- Authorization volume
- Auto-decision rate
- Decision SLA met rate
- Avoidable manual reviews
- Claims denial rate
- Denied amount
- Estimated admin savings
- Client value opportunity

## Page 2: Auto-Decision Optimization

Visuals:
- Auto-decision trend by client and month
- Avoidable manual review count by service category
- Policy match vs documentation completeness scatterplot
- Rule refinement recommendation table

Business question:
- Where can Cohere increase auto-decisioning without weakening clinical safeguards?

## Page 3: Claims and Cost Outcomes

Visuals:
- Denial rate by decision path
- Denied amount by service category and payer client
- Paid-to-allowed ratio by decision source
- Claim denial reason breakdown

Business question:
- How are authorization decisions connected to downstream claims and payment outcomes?

## Page 4: Client Reporting

Visuals:
- Client monthly KPI scorecard
- KPI exception list
- SLA risks
- Client value opportunity ranking

Business question:
- What should client delivery teams discuss in the next business review?

## Page 5: Clinical Rule Refinement

Visuals:
- Rule type performance matrix
- Review volume by policy rule
- Recommended action tracker
- Metric tracking before/after tuning

Business question:
- Which clinical decision rules should be tuned, monitored, retired, or supplemented with documentation prompts?
