# Recruiter Summary

## Project

Prior Authorization Auto-Decisioning & Claims Value Analytics

## Target Role

Cohere Health - Healthcare Analyst II

## Six-Second Impression

This project shows healthcare analytics work directly aligned to Cohere's prior authorization, utilization management, claims analytics, client reporting, KPI tracking, and rule-refinement needs.

## What This Demonstrates

- SQL analytics across authorization, claims, client, provider, and clinical rule data.
- Power BI/Tableau-ready KPI exports.
- Prior authorization auto-decisioning analysis.
- Claims denial and financial exposure analysis.
- Client value opportunity ranking.
- Clinical rule refinement recommendations.
- Stakeholder-ready documentation and executive findings.

## Generated Metrics

- Authorization volume analyzed: 18,500
- Claims volume analyzed: 28,500
- Auto-decision rate: 45.81%
- Decision SLA met rate: 82.71%
- Avoidable manual reviews identified: 4,268
- Claims denial rate: 19.92%
- Denied amount reviewed: $5,521,915.19
- Estimated auto-decision admin savings: $167,361.50
- Client value opportunity: $277,560.03

## Recommendation

Move clean, policy-matched, documentation-complete requests from manual nurse review into the auto-decision path while preserving clinical and compliance safeguards.

## Why It Matters For Cohere

The project mirrors the type of analysis a Healthcare Analyst II would perform: monitor authorization performance, connect decisions to claims outcomes, identify rule-refinement opportunities, prepare client-facing insights, and communicate measurable business value.
